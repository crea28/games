# Territoires

A turn-based territory strategy game for 2 to 4 players, playable in the browser from a single HTML file, with no server and no install needed.

Players place blocks on a 20×20, 30×30 or 60×60 board, recruit an army, open chests to win cannons, and try to capture their opponents' Capitals. Each color can be played by a human or by the computer (easy or medium level), and the interface is in French.

The game is loosely inspired by Blokus-style block placement, and the rules come from ideas by kids.

> **Prototype notice:** this is an experimental prototype built through *vibe coding*, in a conversational, AI-assisted workflow. The rules are still evolving, the code has not been reviewed or tested the way production software would be, and bugs are expected.

## Main features

- Block placement on a grid, with a Capital to defend and chests to open
- Army of soldiers, villagers, archers and cavalry, plus cannons and fortresses with ranged attacks
- Combat resolved by comparing attack and defense, with dice to break ties
- Hot-seat play on one screen, or against a computer opponent
- Three board sizes for short, medium and long games
